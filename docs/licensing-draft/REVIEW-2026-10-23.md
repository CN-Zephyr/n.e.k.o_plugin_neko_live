## 发现及修正

| 问题 | 修正 | 相关条款 |
| --- | --- | --- |
| 一般商业限制可能被读成取消主播免费例外 | 明确免费用途的优先级，并限制例外只覆盖所列行为 | 第 2、6 条 |
| FAQ 提及录像剪辑，正文原来只写直播 | 正文明确本人直播准备、录制、回放、剪辑、内容发布及只展示效果的演示；允许自用修改版 | 第 3 条 |
| 主播内容订阅与软件会员权益容易混同 | 区分内容收入和软件获取、解锁、席位、部署、托管费用；“捐赠”名称不决定豁免 | 第 3 条、第 6 条第 3 项 |
| 个人私人仓库可能被误认为一律禁止，或一律允许复制其他项目 | 允许本人实例的配置、补丁和运行辅助脚本；独立项目组件提取不因未公开而豁免 | 第 2 条、第 6 条第 1 项 |
| 只为一个客户服务或暂未收费可能规避商业授权 | 软件服务不以多个客户或已经盈利为前提；商业免费试用、广告补贴不自动豁免 | 第 3、6 条 |
| 服务商与主播客户的权限可能混为一谈 | 本人直播和商业服务分别判断；主播免费不替服务商授权，服务商业务也不取消主播独立合法副本的免费用途 | 第 3 条及单独授权模板 |
| 普通云服务器和软件专用托管业务容易混同 | 允许主播自管通用资源上的合法实例，不把通用资源或模型费用当成购买本软件服务 | 第 3 条 |
| 只使用公开接口的原创适配可能被误认为搬代码 | 没有受保护实现复制时不触发跨项目复制条款；软件本身的运行及交付仍须有相应权限 | 第 4、7 条 |
| 分享官方链接可能被要求携带完整许可或申请授权 | 将仅分享链接与交付软件副本分开；链接不额外授予软件服务或代码集成权 | 第 5 条 |

## 人工核对的场景

下表是审阅判断及预期边界，不是程序自动测试结果。

| 场景 | 拟定结论 | 对应范围 |
| --- | --- | --- |
| 主播本人开播，收到礼物、打赏、广告、赞助或内容订阅 | 免费允许 | 第 3 条 |
| 已签约 MCN、账号由机构登记，但仅运行本人内容实例 | 不仅因此另收许可费 | 第 3 条 |
| 主播修改本人实例后开播，并发布获利的本人录像、剪辑或演示 | 免费允许，不交付修改软件 | 第 2、3 条 |
| 本人主播同时收费接软件部署订单 | 本人内容免费；部署业务须授权 | 第 3、6 条 |
| 软件服务商只有一个主播客户，或客户本人免费 | 服务商仍须相应授权 | 第 3、6 条 |
| 软件 SaaS、广告补贴平台或商业免费试用 | 不因暂不收客户费用而豁免 | 第 3、6 条 |
| 收“直播打赏”后发软件包、开软件席位或提供托管 | 按软件交付和服务授权，不按收入名目豁免 | 第 3、6 条 |
| 自管通用云资源上运行本人合法实例 | 本人内容免费；第三方资源费用及其条款另算 | 第 3 条 |
| 私人仓库只存本人实例配置、补丁、必要启动脚本 | 免费允许 | 第 2 条 |
| 从软件提取业务模块到另一个未公开项目 | 须授权，除已有独立有效许可或法定例外 | 第 6、7 条 |
| 其他项目免费、开源并保留署名，但复制受保护实现 | 须授权；免费和署名不代替许可 | 第 6 条 |
| 换界面、名称、语言后独立发行复制改编的实现 | 须授权 | 第 6 条 |
| 不复制实现，只编写公开 API 的原创适配 | 不因此构成搬用代码；受限软件的运行交付另算 | 第 4、7 条 |
| 复制 SDK、类型定义或样例用于扩展 | 以明确的文件范围和开发者例外为准 | 第 4 条 |
| GitHub 站内查看、fork | 保留平台已有权利，不等于商业或独立发行许可 | 第 4 条 |
| 为本项目提交修复、评审分支或 PR | 在贡献评审范围内免费允许 | 第 2、4 条 |
| 无偿转发官方原版包并保留声明，不捆绑其他产品 | 按条件允许 | 第 5 条 |
| 只贴官方获取链接，不交付软件 | 链接本身不触发额外授权 | 第 5 条 |
| 免费帮朋友安装合法官方版本，无商业目的 | 允许，不附带跨项目或独立修改版发行权 | 第 2、5 条 |
| 后来依法从历史 MIT/Apache 版本取得相同代码 | 按其有效旧许可判断，不能追溯取消 | 第 7 条及使用说明 |
| 完全独立实现相似功能，不复制受保护表达 | 不因功能相似被禁止 | 第 7 条 |
| 用户内容、生成输出或第三方模型及素材 | 不自动成为团队代码许可标的，分别遵守实际权利 | 第 1、3、7 条 |
