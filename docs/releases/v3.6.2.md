# 直播助手 v3.6.2

修复 B 站账号面板的登录检查分流，并补齐昵称与真实支持事件之间的证据边界。

- 普通“检查登录”直接查询现有凭据，只有进行中的扫码流程才查询二维码结果，避免后台残留扫码会话影响有效账号的面板判定。
- 等待扫码和手机确认时保留二维码；登录完成、二维码过期或会话丢失后，恢复普通登录态检查。不新增自动轮询。
- 进场、弹幕、头像互动、礼物、SC、上舰、关注及个人／房间点赞都明确区分昵称与事件证据。“送提督”“老板”等昵称不能证明送礼或上舰；致谢只能针对本次已验证的事件类型。
- 精简完整匹配的重复事实约束，保持单条提示词 1000-token 上限，覆盖长昵称、表情和历史追问场景。

插件 ID、配置结构与宿主基线不变，无需迁移凭据或观众档案。本次不新增依赖、后台轮询、模型调用或持久化数据。

本地模拟覆盖有效登录、残留／悬挂扫码请求、扫码状态切换及“进场后点赞”的实际投送提示词；全量回归和面板交互检查通过。另一台电脑的实际网络耗时与模型口播仍需在更新后复测，本版不保证固定连接耗时。
