# 直播助手 v3.6.1

修复观众档案与提示词投送不一致造成的“老观众被当成新面孔”，并补齐相同问题的其他入口。

- 普通弹幕、头像互动、进场和个人支持事件都携带必要的观众熟悉度事实；记忆关闭或可选上下文被预算裁剪时仍保留。无可靠记录时使用中性称呼。
- 礼物、SC、上舰、关注和个人点赞复用同一规则。房间总点赞不绑定个人档案；只有 SC 正文作为观众发言处理。
- 锐评提示改用当前互动措辞，避免对主动请求锐评的老观众暗示“首次出场”。首次锐评的触发与去重逻辑保持现有行为。
- 观众印象和已有证据支持的话题偏好可以同时进入可选记忆提示；继续遵守原有白名单、数量上限、记忆开关和提示词预算。

插件 ID、配置结构和宿主基线不变，无需迁移观众档案。首次见面日期仍仅在相关问题中提供；本补丁不向模型公开原始互动次数。

本地合成事件回归已覆盖两种直播模式、图片开关、支持事件、长昵称与提示词预算。实际模型措辞和直播间听感仍按 [Windows 实播验收](../solo-stream-test-guide.md#windows-实播验收) 检查；合成回归不代表真实直播间验收。
