# 直播助手 v3.6.0

新增直播词表、观众隐私管理和开发者头像预览，并改进换房、停播和直播输入处理。

- 可在隐私设置配置词表，拦截匹配的弹幕、昵称和插件提交内容。生成后文本拦截及回复长度整形需要同时更新到支持对应契约的宿主。
- 观众档案达到容量上限时，控制台显示具体原因。开发者工具可查看处理后的头像缩略图。
- 停播后可在支持相应接口的宿主按平台、角色和观众撤回该观众的直播记忆。失败可从控制台恢复处理。
- 普通弹幕增加按观众限流。礼物候选队列、事件订阅、头像读取和入站包解析增加资源上限。
- 修复监听切换、停播清理及凭据保存中的竞态。支持读取带来源证明的宿主回复记录，以减少重复接话。

插件 ID 仍为 `neko_live`。旧宿主继续执行插件侧输入和提交检查，回复整形及生成后文本拦截随配套宿主更新生效。正式安装包支持 B 站和 Twitch，抖音监听仍需 Windows x64 源码版和桥接程序。

本地使用合成弹幕和已试听音频覆盖了 SDK 投送、宿主排队和 Electron 播放。真实直播间和正式桌面安装包的试播按 [Windows 实播验收](../solo-stream-test-guide.md#windows-实播验收) 记录。
