# 直播助手 v3.5.1

修复点歌权限与管理面板、直播角色归属，以及记忆、凭据和停播清理的异常处理。
本版接续 v0.3.5，按维护者指定使用 v3.5.1 版本号。

## 修复

- 显式指定角色连接直播间时，正确使用该角色；重叠连接请求只允许当前成功连接绑定角色，已有直播会话不被重复连接抢走归属。
- 弹幕选取保留粉丝牌等级和舰长等级，供点歌权限判断使用。
- 开放点歌记录刷新和插队的面板动作权限，修复管理面板调用被拒绝的问题。
- 直播记忆失败重试保留原批次、幂等键和主体 epoch，新消息独立排队，避免用新身份重复提交旧内容。
- Twitch 查询房间时正确保存临时客户端刷新的凭据，并保护登出、重新授权与保存之间的竞态。
- 停播时对场景恢复进行有界重试；仍失败时保留待清理状态并报告失败，不再误报清理完成。
- 观众档案的一次读写固定使用同一存储目录，避免配置热切换把旧目录内容写入新目录。

## 升级与边界

- 插件 ID 仍为 `neko_live`，无需迁移现有配置与观众档案。
- 更新后重启 N.E.K.O 后端，以加载新增的点歌面板动作声明。
- 延续 v0.3.5 的打包策略：安装包不包含 `douyinLive.exe`，抖音监听仍因缺少桥接而不可用；B 站和 Twitch 不依赖该文件。
- 已完成本地自动回归：2578 通过、1 跳过；Hosted UI、静态检查和插件检查通过。
- 真实直播间验收留待测试人员完成。本版不声称已验证实际播出、真实账号凭据刷新或实际点歌队列效果。

## 试播重点

- 粉丝／舰长点歌权限，以及点歌记录刷新和插队。
- 指定角色连接、换房重连与停播后恢复普通聊天。
- Twitch 房间查询、连接和凭据刷新（使用 Twitch 时）。
