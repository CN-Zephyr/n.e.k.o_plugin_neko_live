# 直播助手 v0.3.5

修复 B 站直播人数问答和无问号弹幕识别，并更新发行包的配置布局。

## 变更

- 问当前直播间有多少人时，猫猫可以使用 B 站近 120 秒内报告的在线数。收到的 0 是有效值，数据缺失或过期时提示模型说明未知。高能榜计数继续服务原有门控。
- 识别常见的无问号问句，例如「直播间有多少人」「直播多久了」「直播多长时间了」。时长改动只涉及问句识别。
- 人数提示只在相关弹幕回复中加入。提示词接近宿主上限时，优先使用精简的直播场景说明。
- 运行默认值移到 `config.example.toml`，并新增 `pyproject.toml`。宿主继续使用已有用户配置。

## 升级与边界

- 插件 ID 仍是 `neko_live`。房间号、启停状态和用户数据无需手动迁移。
- 人数识别使用文本规则。带多层指代的弹幕可能识别不准，自定义角色名与范围关键词重合时也可能漏判。
- 本地测试覆盖了提示词内容、预算限制和配置读取，真实直播间的模型回答仍待验收。
